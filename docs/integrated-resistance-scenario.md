# Integrated resistance scenario

The current layers compose in a reproducible pipeline:

1. A declared allele is mapped to an evidence-bounded capability modifier.
2. The caller translates that measured capability difference into an explicit
   resistance parameter.
3. The ecosystem applies the parameter through `ImmuneInteraction` under a
   shared effector field.
4. The result reports susceptible and resistant biomass separately.

The translation in step 2 is intentionally explicit rather than inferred by
MARSE. A capability multiplier is not automatically a clinical resistance
claim; a future strain model can add source-linked mappings when data support
them.
