# Security and privacy reports

Please **do not open a public issue** for:

- a security vulnerability in MARSE, or
- personal data, credentials or private research data that has been committed
  to this repository.

Report it privately instead:
**[open a private report](https://github.com/Y3K5/MARSE/security/advisories/new)**
(*Security* tab → *Report a vulnerability*). Only you and the maintainers can
see it.

Include what you found and where (file, commit or release) and, for a
vulnerability, how to reproduce it. Do not copy leaked data into the report;
its location is enough.

## Supported versions

MARSE has not reached 1.0. Fixes are made on `main` and ship in the next
release.

## What to expect

MARSE is a research project maintained on a best-effort basis. Reports are
acknowledged as soon as possible. Exposed credentials or personal data take
priority and are handled as described in
[PRIVACY.md](PRIVACY.md#if-something-leaks-anyway).
